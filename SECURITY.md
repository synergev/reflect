# Security policy

Please report vulnerabilities privately through GitHub's
[security advisory form](https://github.com/synergev/reflect/security/advisories/new)
rather than in a public issue. Include steps to reproduce and the version or
commit you tested.

Only the latest release is supported.

Reports that matter most here:

- Prompts, credentials, or captured feedback leaving the machine other than
  through the documented, opt-in OpenRouter detection request.
- A repository or its contents causing Reflect to capture, propose, or commit
  guidance the user didn't write or approve.
- Redaction gaps for common credential formats.
